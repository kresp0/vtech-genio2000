# FUNCTION_CATALOG

Machine-readable data (generated by the tools, not published because it is derived from the firmware): all detected function entries (targets of `CALL`, vectors, API table, dynamic jumps), cross-references, the API table, and `names.json` (proposed names used by the listings).
Name coverage: **only about 35 functions have a name** (those in the table below); the rest appear as `fn_XXXX` in the listings. Confidence level per row; no name comes from the original firmware (there are no symbols in the ROM).
